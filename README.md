# GenAI Intuitions

This repository collects my notes and intuitions for generative AI concepts.
It is structured to keep concept explorations, explanations, and experiments together in one place.

## Repository Structure

- `GenAILearning/`
  - `XX_TOPIC/`
    - `implementation.ipynb` — exploratory notebook for TOPIC concepts
    - `notes_intution.md` — intuition notes and explanations for TOPIC
  - `README.md` — optional folder-specific overview

## Purpose

- Capture the key ideas behind GenAI topics.
- Record intuitive explanations rather than only code.
- Track experiments, research notes, and practical implementation examples.

## How to Use

1. Open the topic folder for the concept you want to study.
2. Review the `notes_intution.md` file for explanations and intuition.
3. Explore the notebook(s) for hands-on experiments and examples.
4. Add a new numbered folder for the next GenAI concept.

## Adding a New Topic

Use the following pattern for new concepts:

1. Create a new folder under `GenAILearning/` with a numeric prefix, e.g. `01_attention/`.
2. Add a `notes_intution.md` file for concept notes.
3. Add an `implementation.ipynb` or other example file for experiments.

## Current Focus
